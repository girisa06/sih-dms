# Demo script — one case, one narrative

Use the seeded mock case once the login/upload flow is merged.

1. Sign in as investigating officer and open the case dashboard.
2. Open the FIR; show its hash and first chain-of-custody event.
3. Upload or reveal a forensic-evidence item; explain that AI processing does not delay upload.
4. Search by case number, a name, or a statutory section; show extracted tags.
5. Open the forensic report, show assignment status and the audit trail, then run verification.
6. Grant prosecutor time-bound access; switch roles and show the permitted view.
7. Show the expired-access state deliberately.
8. Open the chargesheet/court filing and generate the Section 63 BSA certificate.

Before each rehearsal, reset the demo state and keep fallback screenshots for every critical screen.
